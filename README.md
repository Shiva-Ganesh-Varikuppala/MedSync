# MedSync

MedSync is a healthcare medication and prescription management
application designed to help manage prescriptions, medication
schedules, interactions, and pharmacy inventory.

## Tech Stack

- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MySQL
- Authentication: JWT + bcrypt
- API: REST
